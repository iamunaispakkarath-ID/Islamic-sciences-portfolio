# Islamic Sciences Teaching Portfolio — Unais P.

A GitHub Pages-ready portfolio repository focused on Islamic Studies / Islamic Sciences teaching.

## What this portfolio shows
- A newly prepared sample lesson plan on **Arkan al-Salah (the pillars of prayer)**, based on the supplied excerpts from *Fathul Mu'een*.
- A concise summary of relevant teaching experience, including classroom teaching at Darul Hasanath Islamic Complex and online one-to-one Islamic Studies teaching through Dirasa.

## Accuracy and attribution notes
- The Arkan al-Salah lesson plan is a **newly prepared portfolio sample**, not evidence of a lesson previously taught.
- The plan is a teaching-design sample, not a religious ruling. Before using it with learners, verify its terminology and classifications against the exact edition of *Fathul Mu'een*, the commentary being used, and the institution's adopted fiqh framework.
- No scanned pages from the source book are included. This keeps the public repository focused on the authored sample rather than republishing source material.
- Student-created resources are not included unless permission and attribution for public sharing are confirmed.
- Formal teaching credentials should be listed accurately; this portfolio does not imply B.Ed., PGCE, PGDE, QTS, or equivalent licensure.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example, `islamic-sciences-portfolio`).
2. Upload the contents of this folder to the repository root — `index.html`, `style.css`, `README.md`, and `evidence/`.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Copy the published Pages URL into the CV for Islamic Studies / Islamic Sciences applications.

This ZIP prepares the repository files; it does not create or publish a repository automatically.
